⚡技术特点

特点 说明
🚀零依赖 仅使用 macOS 原生工具（AppleScript、Python3）
🔒本地优先 所有数据存储在本地 Apple 账户，隐私安全
📋结构化输出 生成 Apple Notes 兼容的 HTML 格式
🔌可扩展 模块化设计，易于添加新功能
