Section 4

📐 写作框架工具箱

ℹ️ 关于写作框架
好的写作框架能帮助你组织思维、提升表达清晰度。以下框架源自麦肯锡、费曼等业界顶尖思维方法，适用于技术文档、工作汇报、创意写作等多种场景。
🔺 金字塔原理 (Barbara Minto)
🎯 核心结论
论点 A
论点 B
论点 C
事实1
事实2
事实3
事实4
事实5
事实6
核心原则：先给结论，再展开论证。自上而下思考，自下而上总结。
适用场景：工作汇报、技术方案、管理层演示、邮件沟通
📊 MECE 分析法 (McKinsey)
Mutually Exclusive
相互独立，无重叠
Collectively Exhaustive
完全穷尽，无遗漏
核心原则：将问题拆分为不重叠、不遗漏的子类别，确保分析全面且无冗余。
适用场景：问题分析、市场调研、用户分群、功能拆解
📖 SCQA 叙事框架
🌍
Situation
背景情境
⚡
Complication
矛盾冲突
❓
Question
核心问题
💡
Answer
解决方案
核心原则：用「背景→冲突→问题→答案」的叙事弧线引导读者。
适用场景：产品提案、年终总结、故事写作、问题分析报告
⭐ STAR 结构 (apple-cowork 内置)
S
Situation
T
Task
A
Action
R
Result
核心原则：用具体的情境、任务、行动和结果来呈现案例，数据说话。
apple-cowork：使用 ::: star 语法直接创建 STAR 框架
🔍 5W1H 全面分析
What
做什么
Why
为什么
Who
谁负责
When
何时
Where
在哪里
How
怎样做
核心原则：从六个维度全面审视问题，确保不遗漏关键信息。
适用场景：需求分析、事故调查、新闻写作、项目策划
🎓 费曼学习技巧 (Feynman)
1️⃣
选择概念
2️⃣
教给小白
3️⃣
找出缺口
4️⃣
简化类比
核心原则：如果你无法用简单语言解释一个概念，说明你还没有真正理解它。
适用场景：技术学习、知识内化、教学、写技术博客
Section 5

🎯 场景应用模板

💻
科技工作者
推荐框架：STAR + MECE + 金字塔原理
典型工作流
1. 用 STAR 记录 Bug 分析过程
2. 用 MECE 拆分技术方案选型
3. 用金字塔原理写技术提案
4. 通过 Reminders 跟踪开发任务
5. 用 Calendar 管理站会和评审
📊
工作总结与汇报
推荐框架：金字塔原理 + SCQA + STAR
写作模板
结论先行（金字塔）→ 本季度完成 X 项目...
背景铺垫（SCQA）→ 面对 Y 挑战...
案例论证（STAR）→ 具体项目分析...
数据支撑 → 关键指标提升 Z%...
下一步 → Q2 重点方向...
✍️
创意写作 / 小说
推荐框架：SCQA + 三幕式结构 + 角色弧
小说排版结构
世界观设定 → Frontmatter 存角色/设定属性
大纲管理 → Callout 标注伏笔、高潮、转折
章节追踪 → Reminders 追踪写作进度
灵感捕获 → 随时创建笔记记录灵感
修订日程 → Calendar 安排修改和校对

🤝
会议管理
推荐框架：5W1H + 金字塔原理
完整工作流
会前 → create-event.sh 创建日程
议程 → 笔记创建议题大纲（5W1H）
会中 → 实时记录讨论要点（Callout）
会后 → event-to-reminder.sh 创建行动项
跟进 → Reminders 追踪任务完成

🧰 思维工具箱

🎯 第一性原理
回归事物本质，从基本事实出发推理，而非类比已有经���。
适用：创新突破、架构设计
💎 双钻模型
发散→收敛→发散→收敛。先探索问题空间，再聚焦解决方案。
适用：产品设计、UX 研��
🧠 系统思维
看全局而非局部，关注要素间的反馈循环和涌现行为。
适用：复杂问题、组织管理
🎩 六顶思考帽
白(事实)·红(直觉)·黑(风险)·黄(价值)·绿(创意)·蓝(控制)
适用：头脑风暴、团队讨论
