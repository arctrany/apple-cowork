# Apple Notes 笔记本管理和标签系统

## 概述

本工具提供完整的 Apple Notes 笔记本层级管理和标签索引系统，灵感来自 Notion/Obsidian。

---

## 快速开始

### 1. 创建文件夹结构

```bash
# 创建单层文件夹
./create-folder.sh "技术文档"

# 创建嵌套文件夹层级
./create-folder.sh "技术文档/Apple 生态"
./create-folder.sh "项目/apple-cowork/文档"

# 指定账户（默认 iCloud）
./create-folder.sh "个人/日记" --account "On My Mac"
```

### 2. 创建带标签的笔记

```bash
# 使用参数定义标签和属性
./note-with-style.sh \
  --name "项目总结" \
  --file "summary.md" \
  --tags "Apple Notes，技术文档，自动化" \
  --status "已完成" \
  --owner "张三" \
  --module "Apple Notes 工具" \
  --folder "技术文档"

# 从管道创建
echo "# 标题

这是内容" | ./note-with-style.sh \
  --name "快速笔记" \
  --tags "快速笔记" \
  --status "进行中"
```

### 3. 更新索引笔记

```bash
# 扫描默认目录并更新索引
./update-index.sh

# 自定义扫描目录
./update-index.sh --scan-dir "~/Documents/Projects" --output "项目索引"

# 输出到指定文件夹
./update-index.sh --folder "技术文档/索引"
```

## 标签系统

### 标签语法

在 Markdown 文件的 Frontmatter 中定义：

```yaml
---
标签：[Apple Notes, 技术文档，自动化]
状态：已完成
负责人：张三
模块：Apple Notes 工具
截止：2024-12-31
---
```

### 通过命令行参数

```bash
./note-with-style.sh \
  --name "笔记名称" \
  --tags "标签 1, 标签 2, 标签 3" \
  --status "进行中" \
  --owner "负责人" \
  --module "模块名" \
  --deadline "2024-12-31"
```

### 支持的属性

| 属性 | 参数 | 说明 |
|------|------|------|
| 标签 | `--tags` | 逗号分隔的标签列表 |
| 状态 | `--status` | 进行中/已完成/待开始 |
| 负责人 | `--owner` | 任务负责人 |
| 模块 | `--module` | 所属模块 |
| 截止 | `--deadline` | 截止日期 (YYYY-MM-DD) |

## 索引笔记

### 索引功能

索引笔记自动生成，包含：

1. **标签云** - 可视化展示所有标签及笔记数量
2. **按标签分组** - 每个标签下的笔记列表
3. **状态标识** - 显示笔记状态（已完成/进行中等）
4. **未分类笔记** - 没有标签的笔记单独列出

### 索引示例

```
┌─────────────────────────────────────┐
│  📚 笔记索引                         │
│  最后更新：2024-12-31 15:30         │
├─────────────────────────────────────┤
│  🏷️ 标签云                          │
│  Apple Notes(3) 技术文档 (5) ...    │
├─────────────────────────────────────┤
│  🏷️ Apple Notes                     │
│  • Tech Writer 工具实现 [已完成]    │
│  • 标签系统设计 [进行中]            │
├─────────────────────────────────────┤
│  🏷️ 项目文档                        │
│  • 项目总结 [已完成]                │
│  • 会议记录 [进行中]                │
└─────────────────────────────────────┘
```

### 更新索引

```bash
# 手动更新索引
./update-index.sh

# 定期更新（添加到 crontab）
0 9 * * * cd /path/to/scripts && ./update-index.sh
```


## 提示与技巧

### 1. 标签命名建议

- 使用**粗粒度分类** + **细粒度主题**
- 示例：`项目/apple-cowork`、`技术/前端`、`个人/阅读`

### 2. 文件夹 vs 标签

| 维度 | 文件夹 | 标签 |
|------|--------|------|
| 用途 | 粗粒度分类 | 细粒度标记 |
| 层级 | 支持嵌套 | 扁平 |
| 数量 | 单一归属 | 多个标签 |
| 操作 | AppleScript 可管理 | Frontmatter 元数据 |

### 3. 索引技巧

- 为每个主要分类创建独立索引
- 定期清理未使用的标签
- 使用一致性的标签命名

## 故障排除

### 文件夹创建失败

确保 Apple Notes 已开启 iCloud 同步：
1. 系统设置 → Apple ID → iCloud
2. 确保"Notes"已开启

### 索引笔记无法更新

检查扫描目录是否存在：
```bash
ls -la ~/Documents/Notes
```

### 标签不显示

确保 Frontmatter 格式正确：
```yaml
---
标签：[标签 1, 标签 2]  # 方括号 + 逗号分隔
---
```
