# 笔记本管理和标签系统演示

::: star
Situation: Apple Notes 缺乏层级管理和标签索引功能
Task: 设计并实现文件夹管理和标签索引系统
Action: 创建 create-folder.sh、index-generator.py、update-index.sh 等工具
Result: 完整的笔记本管理和标签索引系统，支持文件夹层级、Frontmatter 标签、自动索引
:::

## 核心功能

> [!KEY] 最重要的特性
> 混合式管理：文件夹层级 + Frontmatter 标签 + 索引笔记聚合

## 文件夹层级管理

### 支持的账户

- **iCloud** - 云端同步（默认）
- **On My Mac** - 本地存储

### 创建文件夹结构

```bash
# 创建技术文档结构
./create-folder.sh "技术文档/Apple 生态"
./create-folder.sh "技术文档/AI 工具"

# 创建项目结构
./create-folder.sh "项目/apple-cowork/需求"
./create-folder.sh "项目/apple-cowork/技术方案"
./create-folder.sh "项目/apple-cowork/会议记录"
```

### 推荐文件夹结构

```
Notes/
├── 技术文档/
│   ├── Apple 生态/
│   ├── AI 工具/
│   └── 开发/
├── 项目/
│   ├── apple-cowork/
│   └── 其他项目/
├── 个人/
│   ├── 日记/
│   └── 阅读笔记/
└── 索引/
    └── 笔记索引
```

## 索引笔记

### 索引内容

1. **标签云** - 可视化展示所有标签
2. **按标签分组** - 每个标签下的笔记列表
3. **状态标识** - 显示笔记状态
4. **未分类笔记** - 没有标签的笔记

### 更新索引

```bash
# 基本用法
./update-index.sh

# 自定义目录
./update-index.sh --scan-dir "~/Documents/Notes/项目" --output "项目索引"
```

## 完整工作流

### 项目文档流程

```bash
# 1. 创建文件夹
./create-folder.sh "项目/apple-cowork/需求"
./create-folder.sh "项目/apple-cowork/技术方案"

# 2. 创建需求文档
./note-with-style.sh \
  --name "需求文档 - Apple Notes 集成" \
  --file "requirements.md" \
  --tags "apple-cowork，需求，Apple Notes" \
  --status "已完成" \
  --folder "项目/apple-cowork/需求"

# 3. 创建技术方案
./note-with-style.sh \
  --name "技术方案 - 标签系统" \
  --file "tech-design.md" \
  --tags "apple-cowork，技术方案" \
  --status "进行中" \
  --folder "项目/apple-cowork/技术方案"

# 4. 更新索引
./update-index.sh --folder "项目/apple-cowork"
```
